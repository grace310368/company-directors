# 從公開資訊觀測站推導現任董事名單

核心觀念：觀測站沒有一頁「現任董事名單」可以直接抓。做法是**以最近一次全面改選（或金控重新指派）的當選名單為基礎，依時間順序套用之後每一則董事異動重訊**，推出現任名單，再用「董監事持股餘額明細」驗證。

## 開工前：先跟使用者確認

1. 把公司清單逐家對到正確代號與市場別（上市／上櫃／興櫃／公開發行未上市），列給使用者看。簡稱有歧義時（例如「臺灣金」是臺灣金控，不是臺灣金聯）先問。
2. 說明做法（下面四步驟）與預計產出，確認「資料截至日」。預設是今天，持股明細用最近一個有資料的月份。
3. 產出預設是 Excel。使用者只要快速看的話，可以改在對話中用表格呈現。

使用者已經說過「照之前的做法」時，不用再問，直接做。

## 步驟一：確認代號與公告來源

- 用 `scripts/mops.py lookup <簡稱或關鍵字>` 查代號。也可以參考 `references/known-companies.md` 裡過去查過的對照表。
- 判斷每家的**重訊公告方式**，這一步決定去哪裡抓資料：
  - **本公司公告**：上市櫃公司、多數公開發行公司。
  - **由母公司代為公告**：金控 100% 持股的子公司（銀行、證券、投信等）自己幾乎不發重訊，用自己的代號查會是 0 則。董事異動會以「代子公司○○公告……」的標題出現在**母公司**的重訊裡。
  - 判斷方式：用自己的代號查近 3 年重訊，筆數為 0 或極少，而且公司名稱有金控集團字樣 → 改查母公司。
  - 特例：母公司不在觀測站（例如樂天銀的母公司是日本樂天）時，找台灣的主要法人股東（樂天銀是國票金）。
- **未公開發行公司**（例如合庫證）在觀測站沒有代號，也沒有持股明細，只能從母公司代子公司公告推導，名單標為「未核對」。

## 步驟二：抓重訊、找出基準名單

```bash
python3 scripts/mops.py news <代號> --from 112/01 --to 115/10 -o work/news_<代號>.json
python3 scripts/mops.py filter work/news_<代號>.json [--subsidiary 第一銀行] -o work/board_<代號>.json
```

- `news` 逐月抓重訊清單（發言日期、時間、主旨、序號），存成 JSON。
- `filter` 用董事相關關鍵字篩主旨（見 `references/keywords.md`）。加上 `--subsidiary` 只保留標題含該子公司名稱的公告。
- 往回找到**最近一次全面改選**（股東會改選、股東臨時會補選，或子公司由金控「重新指派／改派全體董事」），以該則公告的名單為基準。查詢期間要往前拉到包含這次改選，一般 3 年任期往回抓 3～4 年就夠。
- 用 `python3 scripts/mops.py detail <代號> <發言日期> <序號> --time <發言時間>` 讀公告全文（序號和時間在 news 的 JSON 裡），取得姓名、職稱、所代表法人、生效日。**一定要讀全文**，主旨通常不含名單。

## 步驟三：依序套用異動

依「生效日」（不是發言日）排序，逐則套用：

| 公告類型 | 套用方式 |
|---|---|
| 全面改選／重新指派 | 整份名單替換 |
| 法人董事改派代表人 | 舊代表人換成新代表人，席次和代表法人不變 |
| 辭任／解任／逝世 | 移除，該席記為「出缺」，直到有遞補公告 |
| 補選／新任／遞補 | 新增 |
| 選任董事長、副董事長、常務董事 | 只改職稱 |
| 延任 | 不改名單，在注意事項記錄延任期限 |

每一則都記到「異動紀錄」表。同一天有多則公告的話，依發言時間排序。

## 步驟四：用持股明細交叉核對

```bash
python3 scripts/mops.py holdings <代號> <民國年> <月> -o work/hold_<代號>.json
```

- 取持股明細中的董事、獨立董事、法人代表人，跟推導名單逐人比對。
- 每位董事的「持股明細核對」欄填：`一致`／`差異`／`未核對`（沒有持股明細、或異動晚於持股明細月份）。
- 當月查無資料就往前一個月，並在說明與來源中註明用了哪個月份。
- **不一致時不要猜**。保留重訊推導的結果，把持股明細多出來或少掉的人寫在備註和總覽注意事項，並標黃。常見原因見 `references/edge-cases.md`。

## 步驟五：產出 Excel

把結果整理成 `examples/sample_input.json` 的格式，然後執行：

```bash
python3 scripts/build_excel.py work/result.json -o 董事名單_<批次名稱>_<資料截至日YYYMMDD>.xlsx
```

腳本會產生固定的四個分頁和格式（藍底白字表頭、黃底提醒、凍結窗格、總覽公式自動計算董事長和人數），細節見 `references/output-format.md`。輸出檔放在使用者看得到的工作目錄。

## 跟上次結果比對（選做）

如果 `examples/` 裡有同一批公司的舊結果（例如 `batch1_1151014.json`），比對新舊名單，在回報中列出「上次以來的異動」，包括新任、卸任、改派和職稱變更。

## 回報方式

完成後用中文簡短回報：

1. 家數、現任董事總數、資料截至日、檔名，再用一句話說明各分頁內容。
2. 推導方法一句話，以及核對結果（幾家一致、哪幾家沒核對）。
3. **需要留意的地方**：逐家列出黃底項目，包括任期屆滿但查無改選、席次出缺、重訊和持股明細不一致、資料來自母公司代公告、造字轉換等。
4. 不要用推測補資料。抓不到的公司要明確說出是哪幾家、原因是什麼。

## 注意事項

- 觀測站有 WAF，連線過密會被擋（回傳「因為安全性考量，您所執行的頁面無法呈現」）。`mops.py` 已內建瀏覽器 UA 和每次請求間隔。被擋時先停 1～2 分鐘再試，不要一直重試。部分雲端 IP 會被整段封鎖，這時請使用者在自己的電腦上執行腳本，把 JSON 傳回來。
- 日期一律用民國紀年 `YYY/MM/DD`。
- 姓名有造字（觀測站以圖片或私用區字元揭露）時，能辨識就轉成一般字，並在備註保留原始寫法；無法辨識就保留原樣，例如 `蔡(文+?)涓`，並建議到公司官網確認。
