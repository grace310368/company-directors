# 輸出格式（build_excel.py 的輸入 JSON）

檔名：`董事名單_<批次名稱>_<資料截至日民國YYYMMDD>.xlsx`，例如 `董事名單_13家金融機構_1151014.xlsx`。

```jsonc
{
  "title": "13家金融機構現任董事會總覽",
  "as_of": "115/10/14",                 // 重訊資料截至日
  "holdings_month": "115年9月",          // 持股明細月份
  "query_period": "112/01～115/10/14",   // 選填，會寫進說明與來源
  "show_announce_method": true,          // 選填；預設是只要有任何一家填了公告方式就顯示該欄
  "companies": [{
    "公司": "第一銀", "代號": "5844", "市場別": "公開發行（未上市）",
    "屆次": "第27屆", "任期": "114/04/10 起",
    "重訊公告方式": "由母公司第一金（2892）代為公告",   // 或「本公司公告」
    "注意事項": "……",
    "highlight": true                     // 選填；預設是注意事項有內容就標黃
  }],
  "directors": [{
    "公司": "第一銀", "職稱": "董事長", "姓名": "邱月琴",
    "身分": "法人董事代表人",              // 法人董事代表人／自然人董事／獨立董事／獨立董事（財政部薦派）
    "代表法人": "第一金融控股(股)公司",     // 獨董和自然人填「—」
    "生效日": "114/04/10",
    "依據重訊日期": "114/04/10",           // 多則用「；」分隔
    "依據重訊主旨": "……",
    "持股明細核對": "一致",                // 只能填 一致／差異／未核對
    "備註": "……"
  }],
  "changes": [{
    "公司": "第一銀", "重訊日期": "114/04/10", "生效日": "114/04/10",
    "異動類型": "重新指派",                // 全面改選／重新指派／改派／辭任／解任／逝世／新任／補選／董事長／延任…
    "內容": "第一金控改派第27屆董事15席（含獨董5席）"
  }],
  "notes": [["項目", "說明"], ...]          // 選填；沒填就自動產生標準的說明與來源
}
```

## 各分頁

1. **總覽**：每家一列。董事長、現任董事人數、其中獨立董事、與持股明細不一致這四欄是公式，從「董事名單」分頁自動計算。最後有合計列和黃底說明。
2. **董事名單**：每位現任董事一列，依公司順序排列，公司內依董事長、副董事長、常務董事、董事、獨立董事排序。
3. **異動紀錄**：最近一次改選以來的所有異動，依公司和生效日排序（腳本會自動排）。
4. **說明與來源**：資料來源、交叉核對、推導方法、查詢期間、子公司重訊、職稱、造字、日期。有造字或其他特殊處理時，自己加到 `notes`。

## 範例

- `examples/sample_input.json`：2 家公司的小範例。
- `examples/batch1_1151014.json`、`examples/batch2_1151014.json`：前兩批 26 家的完整結果（115/10/14）。之後重查同一批公司時，可以拿來和新結果比對，列出「上次以來的異動」。
