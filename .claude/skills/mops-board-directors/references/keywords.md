# 董事相關重訊的主旨關鍵字

`mops.py filter` 內建這三組關鍵字（定義在 `scripts/mops.py` 開頭），需要時可以直接改。

- **納入**：董事、獨立董事、董事長、副董事長、常務董事、法人代表、改派、改選、補選、當選、選任、解任、辭任、逝世、延任、重新指派、指派、審計委員、監察人
- **排除**（多半是董事會的決議事項，跟名單無關）：董事會決議、股利、財報、增資、公司債、取得／處分、背書、資金貸與、庫藏股、薪酬委員、經理人、總經理、發言人、稽核主管、會計主管、財務主管、法說會、重要子公司
- **強制保留**（就算碰到排除字也保留）：董事長、改派、法人董事、獨立董事、當選、重新指派

篩完一定要人工看過清單。常見的漏網之魚：

- 「股東常會重要決議事項」裡面含改選結果，要讀全文。
- 「本公司代子公司公告重要人事異動」。
- 「財政部改派本公司董事」（官股）。
