# 常見特殊狀況與處理方式

以下都是實際遇過的情況。處理原則：**以重訊為準，用持股明細驗證，不一致就標出來，不要自行猜測補上。**

## 任期與改選

- **任期屆滿但查無改選重訊**（例如臺銀證第 6 屆到 115/08/24、合庫銀第 8 屆到 115/09/06）：
  如果屆滿後仍有遞補或解任公告，就視為延任中，維持原名單。任期欄寫「○○～○○（已屆期，未見改選重訊）」，總覽標黃。
- **董事長延任期限過了沒有新公告**（例如臺灣銀凌忠嫄延任到 115/08/09）：持股明細仍列為董事長的話，就維持原狀並標黃說明。
- **子公司沒有股東會**：100% 持股的子公司由金控董事會「重新指派」或「改派」全體董事。屆次寫「114年重新指派」或沿用該公司自己的屆次。
- **任期起訖不明**（重訊只寫生效日）：任期欄寫「○○/○○/○○ 起」。

## 席次變動

- **辭任、解任、逝世**：移除該董事，在注意事項寫「○○於○○辭任／逝世，該席目前出缺」。例如臺企銀王哲男 115/03/06 逝世、兆豐金吳瑛 115/05/27 辭任。
- **同時辭任董事長和董事**（例如華南證黃進明）：拆成兩件事處理，一是新董事長由誰接任，二是原董事席次出缺。
- **法人代表改派**：備註寫「改派，原代表人○○」，生效日用改派生效日。
- **董事轉任他家**：可以在注意事項順便提到（例如吳瑛轉任國票金董事兼總經理），方便做兼任分析。

## 持股明細不一致

| 現象 | 常見原因 | 處理 |
|---|---|---|
| 異動晚於持股明細月份 | 時間差（例如 10/01 換人，持股明細只到 9 月） | 新任者標「未核對」，備註寫明時間差 |
| 已解任的人仍出現在持股明細 | 時間差（申報落後） | 維持重訊推導結果，在注意事項說明 |
| 持股明細有人，但查無任何重訊 | 勞工董事、官股代表的改派常常不發重訊（例如土銀林佳慶、鄒瓊篁） | 把持股明細上的人列入名單，標「差異」；依據主旨寫「（未查到相關重訊）」，原本的人寫在備註 |
| 當月持股明細查無資料 | 該月尚未申報 | 往前一個月查，在說明與來源中註明 |

## 姓名與職稱

- **造字**：觀測站常用圖片或私用區字元揭露罕見字。能從上下文或其他公告判讀的，就轉成一般字（例如蔡炯民、蔡子晧、宋雲峰、謝明峯）。判讀不出來的保留成 `蔡(文+?)涓` 這種寫法，並建議到公司官網確認。都要在備註和說明與來源中記錄。
- **職稱**：董事長、副董事長、常務董事、獨立常務董事、勞工董事以重訊為準。重訊沒有寫的，參考持股明細，並在備註註明。
- **身分欄**用固定值：`法人董事代表人`、`自然人董事`、`獨立董事`、`獨立董事（財政部薦派）`。總覽的獨董人數公式是用「獨立董事*」計算的。
- **代表法人**：獨立董事和自然人董事填「—」。

## 抓取問題

- 遇到 WAF 封鎖（「因為安全性考量」），先停下來。整段 IP 被擋時，請使用者在本機執行 `mops.py`，或請使用者提供觀測站的查詢結果。
- 觀測站改版導致解析不到資料時，`mops.py` 會把原始 HTML 存成 `debug_*.html`。讀這個檔案調整解析方式，不要直接當成「0 則」。
- 新版觀測站（mops.twse.com.tw）是前端動態載入，背後是 `POST /mops/api/<頁面代號>` 的 JSON API。舊版網址（mopsov）連不上時，可以用瀏覽器開發者工具看新版實際送出的參數，再改寫 `mops.py`。
